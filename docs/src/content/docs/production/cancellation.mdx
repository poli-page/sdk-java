---
title: Cancellation
description: How to cancel in-flight requests with thread interrupts or CompletableFuture.cancel.
---

The Java SDK exposes two cancellation idioms — one per facade. Blocking calls honor `Thread.interrupt()`, which surfaces as a `PoliPageException` with `code() == "aborted"` and the message `Request was aborted`. Async calls honor `CompletableFuture.cancel(true)`; the future then completes with the JDK's `CancellationException`, as every cancelled `CompletableFuture` does. Either way the SDK stops at once: the request in flight is cancelled, a wait before a retry ends, and no further request is sent.

## Blocking facade

Interrupt the thread that's waiting inside a `render()` or `documents()` call. The SDK catches `InterruptedException`, restores the interrupt flag, and throws.

```java
Thread worker = Thread.currentThread();

ScheduledExecutorService timer = Executors.newSingleThreadScheduledExecutor();
timer.schedule(worker::interrupt, 5, TimeUnit.SECONDS);

try {
    byte[] pdf = client.render().pdf(input);
} catch (PoliPageException ex) {
    if ("aborted".equals(ex.code())) {
        System.out.println("cancelled");
    } else {
        throw ex;
    }
}
```

## Async facade

Cancel the returned future with `cancel(true)`. The cancellation reaches the stage in flight: the HTTP exchange, the wait before a retry, or the PDF download of `pdf()` / `pdfStream()`.

```java
CompletableFuture<byte[]> future = client.renderAsync().pdf(input);

ScheduledExecutorService timer = Executors.newSingleThreadScheduledExecutor();
timer.schedule(() -> future.cancel(true), 5, TimeUnit.SECONDS);

byte[] pdf = future.get(); // throws CancellationException if cancelled
```

## Cancellation vs timeout

`requestTimeout` (the builder option) is a per-attempt deadline that covers the whole attempt, the answer's body included. Caller cancellation is independent — whichever fires first wins. A timeout is retried; a cancellation never is.

`aborted` errors are **not retried**. The SDK assumes the caller meant it.

## Example

```java
import java.util.Map;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;
import page.poli.sdk.PoliPageClient;
import page.poli.sdk.input.RenderInput;

class Example {
    public static void main(String[] args) throws Exception {
        PoliPageClient client = PoliPageClient.builder()
            .apiKey(System.getenv("POLI_PAGE_API_KEY"))
            .build();

        RenderInput input = RenderInput.builder()
            .project("billing")
            .template("invoice")
            .data(Map.of("invoiceNumber", "INV-001", "total", 1280))
            .build();

        CompletableFuture<byte[]> future = client.renderAsync().pdf(input);

        ScheduledExecutorService timer = Executors.newSingleThreadScheduledExecutor();
        timer.schedule(() -> future.cancel(true), 10, TimeUnit.SECONDS);

        try {
            byte[] pdf = future.get();
        } finally {
            timer.shutdown();
        }
    }
}
```
