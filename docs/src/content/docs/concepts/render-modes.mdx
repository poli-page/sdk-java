---
title: Render input
description: Every render method takes one input type, a project and template by slug, rendered from the copy published in the key's environment.
---

Every render method (`render().pdf`, `render().pdfStream`, `render().document`, and the `renderToFile` helper) takes the same input type, `RenderInput`: a project and one of its templates, by slug, plus the `data` map that fills the template.

## The input

```java
RenderInput input = RenderInput.builder()
    .project("billing")
    .template("invoice")
    .data(Map.of("invoiceNumber", "INV-001", "total", 1280))
    .build();

byte[] pdf = client.render().pdf(input);
```

- `project`, `template`, `data` — required; `build()` throws `NullPointerException` when one is missing. `data` may be empty.
- `format`, `orientation`, `locale`, `metadata` — optional; an unset field is not sent.
- `idempotencyKey` — optional; sets the `Idempotency-Key` header instead of the SDK's generated UUID. Not part of the request body.

The SDK sends only these fields. `RenderInput` has no `version`.

## Which copy is rendered

The API resolves the environment from the API key and renders the project's copy published in that environment. There is no version to pick, and no key renders the draft: publish the project to the key's environment first. A project that is not published there gets `404 PROJECT_NOT_IN_ENVIRONMENT`.

Templates live in your project, so anyone with dashboard access can edit and publish them without touching code. To preview a template or render inline HTML while you design it, use the playground: [play.poli.page](https://play.poli.page).

## Example

```java
import java.util.Map;
import page.poli.sdk.PoliPageClient;
import page.poli.sdk.input.RenderInput;
import page.poli.sdk.model.PageFormat;

class Example {
    public static void main(String[] args) {
        PoliPageClient client = PoliPageClient.builder()
            .apiKey(System.getenv("POLI_PAGE_API_KEY"))
            .build();

        RenderInput input = RenderInput.builder()
            .project("billing")
            .template("invoice")
            .data(Map.of("invoiceNumber", "INV-001", "total", 1280))
            .format(PageFormat.A4)
            .locale("en-US")
            .metadata(Map.of("customerId", "cust_123"))
            .build();

        byte[] invoicePdf = client.render().pdf(input);
    }
}
```
