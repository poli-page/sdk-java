title: Configuration
description: Per-client options for timeouts, retries, and observability hooks.
---

The `PoliPageClient.Builder` accepts fluent setters for every option. Only `apiKey` is required. Defaults match the canonical SDK behavior shared by every Poli Page SDK.

## Available options

- `apiKey(String)` (required) — an API key of one environment, `pp_{env}_…` (e.g. `pp_sandbox_…`). See [authentication](../authentication/).
- `baseUrl(URI)` — override the API endpoint. Defaults to `https://api.poli.page`.
- `requestTimeout(Duration)` — per-attempt timeout, covering connecting, the answer's headers and its body. Defaults to `Duration.ofSeconds(60)`. Also bounds the presigned-URL download.
- `maxRetries(int)` — maximum retry attempts for retryable errors. Defaults to `2` (three total attempts).
- `retryDelay(Duration)` — initial retry backoff. Defaults to `Duration.ofMillis(500)`. Doubles each attempt with jitter; a `Retry-After` header replaces it.
- `onRetry(Consumer<RetryEvent>)` — fired just before each wait between attempts, with the attempt about to start (`2` for the first retry). Use for metrics, traces, structured logs.
- `onError(Consumer<Throwable>)` — fired once with each error a call is about to throw.
- `onRequest(Consumer<RequestEvent>)` — fired before each API attempt, retries included (`method`, `url`, `attempt`).
- `onResponse(Consumer<ResponseEvent>)` — fired after each 2xx API answer, once its body is read (`status`, `requestId`, `durationMs`).

`onRequest`, `onResponse` and `onRetry` cover calls to the Poli Page API only. The PDF download from the presigned URL (`render().pdf`, `render().pdfStream`, `renderToFile`, `documents().downloadPdf`) is a single attempt outside the retry loop: only `onError` fires for it, when it fails.

## Example

```java
import java.time.Duration;
import page.poli.sdk.PoliPageClient;

class Example {
    public static void main(String[] args) {
        PoliPageClient client = PoliPageClient.builder()
            .apiKey(System.getenv("POLI_PAGE_API_KEY"))
            .requestTimeout(Duration.ofSeconds(30))
            .maxRetries(3)
            .retryDelay(Duration.ofMillis(250))
            .onRetry(event -> System.out.println(
                "retry attempt=" + event.attempt() + " reason=" + event.reason()))
            .onError(err -> System.err.println("terminal: " + err.getMessage()))
            .build();
    }
}
```
