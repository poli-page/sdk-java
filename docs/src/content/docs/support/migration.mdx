This page tracks breaking changes between major versions of `page.poli:sdk`. For the full per-release diff, see the [changelog](../changelog/).

## v0.11.0

Conformance with the Poli Page API contract v1.3.0: three error codes are never retried, `PoliPageErrorCode.DOWNLOAD_FAILED` is now `"DOWNLOAD_FAILED"` (recompile against the new version), and SDK error messages follow the SDK specification. The full entry is in [`MIGRATION.md` in the repo](https://github.com/poli-page/sdk-java/blob/main/MIGRATION.md#from-0100-to-0110).

## v0.10.0

The first release of the Java SDK, on the environments contract. The full entry is in [`MIGRATION.md` in the repo](https://github.com/poli-page/sdk-java/blob/main/MIGRATION.md).

Short version: an API key carries its environment (`pp_{env}_…`, e.g. `pp_sandbox_…`) and a render uses the project's copy published in that environment. `RenderInput` (formerly `ProjectModeInput`) is the only render input and has no `version`. `render().preview` and inline-HTML rendering are gone: preview templates and inline HTML in the playground, [play.poli.page](https://play.poli.page). `documents().preview(id)` stays. Error codes come from the API verbatim (e.g. `TEMPLATE_NOT_FOUND`, `PROJECT_NOT_IN_ENVIRONMENT`).
