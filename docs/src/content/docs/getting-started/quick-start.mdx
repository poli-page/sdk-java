## Set your API key

Use a `sandbox` key (`pp_sandbox_…`) of a fresh organization, and export it into the environment your program runs in:

```bash
export POLI_PAGE_API_KEY=pp_sandbox_x   # replace with your key
```

## Render a PDF

Every organization gets a `getting-started` project, published into its `sandbox` environment when the organization is created, with a `welcome` template. A sandbox key renders it with no setup:

```java
import java.util.Map;
import page.poli.sdk.PoliPageClient;
import page.poli.sdk.input.RenderInput;

class Example {
    public static void main(String[] args) {
        PoliPageClient client = PoliPageClient.builder()
            .apiKey(System.getenv("POLI_PAGE_API_KEY"))
            .build();

        RenderInput input = RenderInput.builder()
            .project("getting-started")
            .template("welcome")
            .data(Map.of("name", "SDK Demo"))
            .build();

        byte[] pdf = client.render().pdf(input);
    }
}
```

`pdf` is a `byte[]`. Write it to disk, stream it to S3, or return it directly from an HTTP handler. Sandbox renders are watermarked and are not counted toward your quota.

`getting-started` is a normal, editable project: in an organization that renamed it, deleted it or removed it from `sandbox`, the API answers `404 PROJECT_NOT_FOUND` or `404 PROJECT_NOT_IN_ENVIRONMENT`, so use a fresh organization to follow along.

## Your own templates

There is no version to pick: a render uses the project's copy published in the API key's environment. Publish your project to the environment of the key you render with, then swap the slugs. To preview a template or render inline HTML while you design it, use the playground: [play.poli.page](https://play.poli.page).

## Example

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Map;
import page.poli.sdk.PoliPageClient;
import page.poli.sdk.input.RenderInput;

class Example {
    public static void main(String[] args) throws Exception {
        PoliPageClient client = PoliPageClient.builder()
            .apiKey(System.getenv("POLI_PAGE_API_KEY"))
            .build();

        RenderInput input = RenderInput.builder()
            .project("getting-started")
            .template("welcome")
            .data(Map.of("name", "SDK Demo"))
            .build();

        byte[] pdf = client.render().pdf(input);
        Files.write(Path.of("./welcome.pdf"), pdf);
    }
}
```
